# 0.18.0

- Sync protocol handling and core with [Exclave dev at 5e21eb87](https://github.com/ExclaveNetwork/Exclave/commit/5e21eb87d1e658bd300e47d02d5c719db2028597)
- Update Hysteria 2 to 2.13.0-1 and bundled NaiveProxy to 154.0.8037.49-5
- Update VLESS/VMess transports, TUIC, ShadowQUIC, Snell and TrustTunnel handling
- Add MASQUE and HTTP/2/3 CONNECT-UDP settings
- Add NaiveProxy tunnel/idle timeouts and Snell obfuscation URI
- Remove OLCRTC/OLCNG support and its bundled executable
- Restyle preset profile fields, keeping direct text entry and suggested values in one field
- Update CA handling, dependencies, build instructions and README

Existing OLCRTC profiles and chains or balancers that depend on them are
removed on upgrade. Rules pointing to those profiles are disabled; other
profiles, traffic counters and profile icons are retained.
